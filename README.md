# Jonathan Benitez — Portfolio & Resume

Personal portfolio, project showcase and printable resume.

**Live site:** https://beniteznathan.github.io/showcase/

## Editing

Everything lives in a single `index.html` — no build step.
All content (projects, services, job history, skills) is in the `SITE` object near the bottom of the file; edit it and commit, and GitHub Pages redeploys automatically.
